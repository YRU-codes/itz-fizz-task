#itz-fizz-task

here I have developed the hero section of the itz-fizz landing page where I have developed the ui using the normal tailwindcss and animated it with the gsap

GSAP it stands for greensock animation platform, it is a javascript library by which we can design the element, svg etc.

i also tried to use the typescript for maintaning the data type, for eg. props in child element and some array as well.


#to-run-project
cd its-fizz-task or open the its-fizz-task inside the code editor
npm i - to install the packages

npm run dev - to run project
